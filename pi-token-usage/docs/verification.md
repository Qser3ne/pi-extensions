## 首次交付的独立审查与修复

一次只读独立审查指出四项重要问题，均先运行失败回归再修复，并重跑完整测试：

1. Pi 带标签分支会重接 parentId：原先 20 tokens 被计为 40；身份现在忽略树链接，保留事件时间和内容。
2. 子会话继承历史可能掩盖缺失用量：保存来源/创建时间元数据，并排除继承上下文及无关 usage；调用边界不确定时明确警告。
3. 通过符号链接选择的根目录与子会话引用不匹配：仅在已选择根目录的别名范围内规范化路径，不扩大扫描。
4. 截止时间后的更大汇总可能替换窗口内数据：在协调汇总前排除查询终点之后的记录。

补充修复内存会话空路径被展开为 cwd 的问题。缓存元数据协议升级到 2，旧快照失效重建。未二次派发审查；修复由 RED→GREEN 回归和完整测试验证。
