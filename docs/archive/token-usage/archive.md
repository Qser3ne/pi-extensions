# token-usage

## Purpose

通过 Pi 用户命令查询本机已保存会话在滚动时间窗口内的 token 用量，跨项目、会话和 provider 汇总，并显式说明本地数据的覆盖限制。

## Requirements

### Requirement: 单一查询命令

扩展 SHALL 仅注册 `tokens` 命令，接受 `/tokens xh` 和 `/tokens xd`，其中 x 为可安全表示的正整数。扩展 MUST NOT 注册独立时间快捷命令或接受省略单位的数字。

#### Scenario: 小时和天数查询

- **WHEN** 用户执行 `/tokens 24h` 或 `/tokens 7d`
- **THEN** 扩展分别查询从执行开始时刻向前 24 小时或 7 × 24 小时的用量
- **AND** 时间窗口两端均包含在内，不按本地午夜划分

#### Scenario: 无参数或非法参数

- **WHEN** 用户执行 `/tokens`、`/tokens 15`、`/tokens help` 或传入零、负数、小数、非法单位或溢出时长
- **THEN** 扩展显示用法或错误，不执行统计查询、不触发模型回复

### Requirement: 本机记录覆盖边界

扩展 SHALL 递归读取 Pi agent 数据目录的 `sessions/` 和当前会话的非空存储目录，包含其中已保存的子代理。扩展 MUST NOT 以当前项目或 provider 作为过滤条件，MUST NOT 读取凭据、查询服务商后台或扫描未选择的磁盘目录。

#### Scenario: 跨项目和渠道

- **WHEN** 被扫描目录内的多个项目或 provider 在窗口内有有效用量记录
- **THEN** 它们均参与总量统计，安装前的已有记录也可查询

#### Scenario: 根目录别名和内存会话

- **WHEN** 用户选择的根目录是符号链接，或当前会话没有持久化目录
- **THEN** 被选根目录的别名及子会话引用按同一物理来源匹配
- **AND** 空会话目录不会展开为当前工作目录，递归过程不跟随目录内部的任意符号链接

#### Scenario: 不可覆盖的历史

- **WHEN** 用量发生在其他机器、其他客户端、未选择的自定义存储目录，或源记录已删除、未保存、未报告 usage
- **THEN** 扩展不承诺恢复这些用量，报告标明来源是本机已保存记录而非服务商账单

### Requirement: 真实用量口径

扩展 SHALL 统计 assistant 回复、工具结果报告的嵌套模型 usage、独立 usage 条目、压缩摘要和分支摘要的有效用量。总量 SHALL 优先使用有效 `totalTokens`，缺失时以 `input + output + cacheRead + cacheWrite` 回退。扩展 MUST NOT 估算文本 token 或把上下文长度当成消耗。

#### Scenario: 缓存及思考用量

- **WHEN** 记录包含输入、输出、缓存读取、缓存写入以及 reasoning 或 cacheWrite1h
- **THEN** 分别汇总四项主要明细
- **AND** reasoning 已属于输出、cacheWrite1h 已属于缓存写入，不再次相加

#### Scenario: 原始事件时间

- **WHEN** 旧会话在查询窗口内继续产生用量，或扫描过程中追加了查询终点之后的更大汇总
- **THEN** 以各用量记录的时间归属窗口，而不是文件创建或修改时间
- **AND** 查询终点之后的汇总不能替换窗口内的有效统计

### Requirement: 复制历史和子代理协调

扩展 SHALL 对 fork/clone 复制的相同用量事件去重，保留内容、时间等事件身份区分，MUST NOT 仅凭短条目 ID 去重。Pi 分支重接树链接本身 MUST NOT 被当成新消耗。被放弃的分支仍 SHALL 参与实际消耗统计。

#### Scenario: 带标签的 Pi 分支

- **WHEN** Pi 复制包含用量的历史并因移除标签而重接 parentId
- **THEN** 同一原始用量仍只计一次，不因树链接变化翻倍

#### Scenario: 可覆盖的原生子代理汇总

- **WHEN** 原生 pi-subagents 或 bg_wait 汇总可以通过已扫描子会话的自身 assistant 用量覆盖
- **THEN** 不再把该汇总作为独立消耗与子会话相加
- **AND** 继承的父历史、独立缓存预热、压缩用量和后代代理用量不充当本次调用自身用量的覆盖依据

#### Scenario: 子代理不完整或调用边界不明

- **WHEN** 子会话缺失、不完整，或重复汇总/重试历史不能证明独立调用边界
- **THEN** 可识别汇总按身份协调，仅保留最大值回退，未覆盖差额按父级汇总时间归属
- **AND** 报告明确提示时间或完整性不精确、可能是下界；无法识别身份的汇总保留并提示可能重叠，不宣称精确全量

### Requirement: 报告不进入模型上下文

扩展 SHALL 显示时间范围、所有渠道总量、输入/输出/缓存读取/缓存写入明细及来源说明，数值使用完整整数而非 K/M 缩略。报告 MUST NOT 触发模型调用或进入后续模型上下文。

#### Scenario: TUI 和 RPC 查询

- **WHEN** 用户在 TUI 中查询成功
- **THEN** 结果作为可持续查看的自定义条目保存及渲染
- **AND** RPC 模式另以文本通知发送结果

#### Scenario: 会话在查询中被替换

- **WHEN** 查询未完成前发生会话关闭或替换
- **THEN** 原查询不向失效会话写入报告

### Requirement: 可重建的增量缓存

扩展 SHALL 在 agent 数据目录的 `pi-token-usage/cache-v1/` 维护可删除重建的统计缓存，仅保存时间、usage、事件哈希和最小来源信息，MUST NOT 保存对话正文。缓存 SHALL 支持独立进程并发查询，不把缓存当成永久账本。

#### Scenario: 重复查询和常规源文件变化

- **WHEN** 源文件未变化，或仅追加完整记录
- **THEN** 扩展复用已有统计或解析新增完整行
- **AND** 发现替换、截断、同大小改写或无效快照时重新扫描对应文件；已删除源文件不继续累计

#### Scenario: 缓存故障或历史原地改写

- **WHEN** 缓存目录不可读写或快照损坏
- **THEN** 扩展回退到可用的源记录扫描，并在不能使用缓存时提示
- **AND** 缓存追加校验不提供针对恶意元数据伪造或刻意保留采样区的原地历史改写的防篡改保证

### Requirement: 数据问题显式提示

扩展 SHALL 对损坏行、无效时间/usage、缺失用量、无法读取的文件及不完整末行给出警告，MUST NOT 将问题静默伪装为完整准确账单。没有有效记录时 SHALL 显示 0。

#### Scenario: 活跃文件末行未完成

- **WHEN** 扫描遇到尚未写完的 JSONL 末行或跨块 UTF-8 内容
- **THEN** 本次不计入不完整末行，下次读取补全后恰好统计一次

#### Scenario: 部分可用数据

- **WHEN** 一部分源记录损坏或不可读，其余记录有效
- **THEN** 统计其余有效记录并显示完整性警告，不以文本估算弥补缺失
