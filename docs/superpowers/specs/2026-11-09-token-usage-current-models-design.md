# 近 24h 快捷命令与当前模型列表过滤

状态：用户已批准设计与计划并确认直接实现。过滤范围为当前 /model 默认列表；原 /tokens 改名为 /token。

## 目标与范围

- 新增 `/token-usage`，固定查询执行时刻向前滚动 24 小时，不是自然日；不接受额外参数。原 `/tokens xh`、`/tokens xd` 改为 `/token xh`、`/token xd`，不保留 `/tokens` 别名。
- 两个命令都只统计执行时当前 /model 默认列表内的 provider/model 组合；整体用量、记录数、模型明细和缓存命中率采用同一过滤口径。
- 用户目的：快捷查看近一天数据，并排除不在当前模型列表中的历史模型；不扩展为服务商账单或模型调用。

## 方案及选择

- 用户选择：有非空 `ctx.scopedModels` 时使用其中模型；否则读取 `ctx.modelRegistry.getAvailable()` 的当前本地快照。与 /model 默认展示范围一致，不追踪选择器临时搜索词或临时切换的 all/scoped 视图。
- 未选：一律使用全部可用模型（忽略 scoped 范围）；只读取 models.json（漏掉其他来源模型）。
- 作者实现建议：命令执行时冻结一份 provider/model 白名单；完整读取及协调历史后、最终聚合前过滤。不将过滤结果持久化到文件/内存快照，不按模型跳过文件。

## 行为细节

- 精确按 provider + model ID 匹配，不跨渠道匹配同名模型，不按展示名称、模糊字符串或当前单一模型推断。
- 缺失 provider/model 的记录，以及无法归到已列出模型的子代理汇总/未覆盖差额，不计入本次查询；原始历史与缓存不删除。这取代此前“未知归属仍计入总量”的查询口径。
- 空模型白名单返回零用量，不退回全历史统计；读取当前名单真正失败时提示查询错误，不静默放宽范围。
- 先完成继承历史去重和子代理协调，再过滤，防止排除部分子记录后把父汇总错误计回其他模型。
- 每次重新读取当前模型名单及时间边界；变化后的名单立即影响下一次查询，已有已保存报告不自动改写。
- 新报告标记“当前模型列表”范围；旧持久报告缺少范围标记时保持原来的标题语义，不能被误标为已经过滤。
- `/token-usage` 多余参数提示其固定 24h 的用法；`/token` 原来的必填单位、正整数规则及真正失败错误提示保持不变。

## 不做的事与约束

- 不发起模型生成、认证刷新或服务商目录请求，不为了统计触发注册表 refresh；使用 Pi 已有本地运行时快照。
- 不改统计总量和缓存命中率公式，不恢复来源脚注或缺失数据警告区，不新增依赖、数据库、后台任务或缓存协议。
- 保留已有有界目录并发及限额内存快照。
- 隔离 worktree、本会话实现与作者自检，不新增子代理；作者自检不等于独立审查。
- 本轮实现、测试、档案同步后，再由用户选择合入、推送及 /reload，不继承上轮的单次推送授权。

## 验收

- 两个命令注册及有效/无效参数；固定时钟下 `/token-usage` 与 `/token 24h` 相同。
- scoped 优先、无 scope 回退 available、名单变化、空名单、名单读取失败及同 ID 跨 provider。
- 被排除记录不影响整体、明细、记录数和缓存率；未知归属排除；完整协调后过滤不引入父子重复统计。
- 磁盘/内存缓存复用及名单切换结果一致，旧报告兼容、真实 RPC 与 bundled loader 回归。
- 完整测试、严格类型检查、打包预检和 diff 检查；同步 README、验证说明、行为档案，并单独提交档案。
